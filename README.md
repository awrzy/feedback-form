# Форма обратной связи

Тестовое задание: форма обратной связи на чистом PHP с сохранением сообщений в MySQL через PDO.

## Стек

PHP 8.5, MySQL-8.4, PDO, HTML5, CSS3, JavaScript ES6+. Без фреймворков, MVC.

## Требования

- PHP 8.0+ 
- MySQL 8.0+
- Веб-сервер (Apache/Nginx) или встроенный сервер PHP

## Запуск

### 1. Скачайте репозиторий.
### 2. Импортируйте файл `database/feedback_db.sql` в БД.
### 3. Настройте подключение

Откройте `app/Core/config.php` и укажите свои данные:

```php
<?php

declare(strict_types=1);

return [
    'db' => [
        'host'     => 'MySQL-8.4',
        'port'     => '3306',
        'dbname'   => 'feedback_db',
        'user'     => 'root',
        'password' => '',
        'charset'  => 'utf8mb4',
    ],
];
```
**Значение `host` для разных окружений:**

| Окружение             | host        |
|-----------------------|-------------|
| Open Server Panel 6.x | `MySQL-8.4` |
| XAMPP / MAMP          | `localhost` |
| Встроенный PHP        | `127.0.0.1` |

### 4. Запустите сервер

Убедитесь, что MySQL запущен. Затем из корня проекта выполните:

```bash
php -S localhost:8000 -t public
```

Откройте <http://localhost:8000> в браузере.

## Проверка работы

1. Заполните поля формы и нажмите «Отправить».
2. Сообщение появится в списке ниже без перезагрузки страницы.
3. В phpMyAdmin откройте `feedback_db` → `messages` — там будет запись.
